# Sample bank statements (made-up data)

Use these to try the automatic CTO / ADB calculator. Download one, then drop it on the calculator or upload it under a self-employed client's bank statements in Documents.

- `enbd-style-12-months.pdf`: 12 months, oldest first, with opening balance
- `mashreq-style-6-months-newest-first.pdf`: 6 months, newest first
- `password-protected-password-1234.pdf`: password is 1234
- `adcb-style.xlsx`: Excel export

All names, amounts and accounts are invented.
