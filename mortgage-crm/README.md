# Mortgage CRM prototype

A clickable prototype of a CRM for mortgage brokers and the advisory team. Everything is in `index.html`; all data in it is made up.

- Open `index.html` in any browser, or share the hosted link.
- Changes testers make are saved only in their own browser.
- Feedback: set `FEEDBACK_WHATSAPP` and/or `FEEDBACK_SHEET_URL` near the top of the script in `index.html`.
  For the Google Sheet option, follow the steps at the top of `google-sheet-feedback-script.gs`.
